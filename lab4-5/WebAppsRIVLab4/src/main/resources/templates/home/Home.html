User Table

Table with data on users of the Student Database Viewer of the National Technical University "Kharkiv Polytechnic Institute".

The table contains the following information about users:

  • String full name of the personal information owner;
  • Role user role in the Student Database Viewer (enum);
  • String username in the Student Database Viewer;
  • String address of corporate mail in NTU "KhPI".
Entrant Table

Table with data on entrants to National Technical University "Kharkiv Polytechnic Institute".

The table contains the following information about entrants:

  • String case number of the personal file;
  • String full name of the entrant;
  • LocalDate date of birth of the entrant;
  • Boolean gender of the entrant;
  • Double rating score of the entrant.
Student Table

Table with data on students of National Technical University "Kharkiv Polytechnic Institute".

The table contains the following information about students:

  • String full name of the personal information owner;
  • FundingType funding type under the study agreement (contract or budget);
  • ScholarshipStatus scholarship accrual status of the student (none, ordinary or enhanced);
  • String address of corporate mail in NTU "KhPI".
