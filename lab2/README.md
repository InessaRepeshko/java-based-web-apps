# Laboratory Training 2 "Study of the principles of using Hibernate, JPA and HQL to access data in web applications"



## Objectives
1. Learn how to develop a web application that displays database table data on a web page and supports CRUD operations using Hibernate.
2. Gain experience in connecting a database to a Java project and implementing CRUD functionality through object-relational mapping (ORM) using Hibernate classes and methods.
3. Improve skills in developing web pages with Java Server Pages (JSP) and utilizing Java Standard Tag Library (JSTL).
4. Enhance the ability to design user-friendly applications.
5. Develop expertise in creating servlets while considering data processing requirements.
6. Acquire skills in implementing data validation for database inputs.



## Task Description
Develop a web application that retrieves and displays data from a single table in a relational database, supports data search, and performs CRUD operations on the selected table using ORM capabilities.

The application should provide:
- Display of table contents on a web page
- Adding new records to the table
- Editing data of a selected record
- Deleting records from the table
- Searching for data by semantic fields



## Implementation Steps
### 1. Project setup
Create a database project using Hibernate ORM and establish a connection between the application and the database.

### 2. Entity class creation
Define an entity class mapping to a database table, create the table, and develop a class with CRUD methods (Create, Read, Update, Delete).

### 3. JSP implementation
Develop JSP pages to display the table’s records, including sorting, filtering, and search functionalities.

### 4. Forms and servlets
Implement forms for adding and editing records, along with servlets to handle these operations.
