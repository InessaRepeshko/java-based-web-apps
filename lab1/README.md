# Laboratory Training 1 "Exploring the Java technology stack for creating and deploying web applications using servlets and JSP"

## Objectives
1. Reinforce knowledge of deploying and configuring the software required for developing web applications using the Java EE technology stack. 
2. Gain an understanding of the structure of Java web applications and the process of their development. 
3. Learn how to create web application projects in the chosen integrated development environment (IDE).
4. Develop skills in creating servlets and designing web pages using servlets. 
5. Acquire experience in implementing page transitions using the forward and `sendRedirect()` methods. 
6. Gain practical experience in creating Java Server Pages (JSP). 
7. Learn how to implement data exchange between servlets and JSP.

## Tasks
### Task 1
Install the necessary software for Java web application development and create a web application. 
1. Install an integrated development environment (IDE) for web application development.  
2. Install a web server or application server for deploying Java web applications.  
3. Create and configure a project in the installed IDE.
4. Develop a web application in the IDE and deploy it on the installed server. The application should display the following student information:
   - The text **"Hello, Web World!!!"**
   - Student’s last name and first name
   - Student’s group number
   - Student’s department affiliation
   - Year of work completion

### Task 2
Develop a web application that displays a list of employees of an IT company on a web page.

### Task 3
Modify the project from Task 2 by adding functionality to navigate to a predefined page from a servlet using the `forward()` and `sendRedirect()` commands.

### Task 4
Develop a web application with the following functionality:
- Display a login page with fields for entering a username and password; upon correct input, the main application page should open.
- Display a menu on the main page, allowing navigation to a JSP page with an employee list presented in a table, without using Expression Language (EL) and Java Standard Tag Library (JSTL).
