# Laboratory Training 3 "Study of the principles of creating complex projects using Spring Boot, Spring Data, Thymeleaf"



## Objectives
1. Gain skills in creating Spring projects and implementing CRUD operations using the framework’s capabilities.
2. Develop skills in creating repositories and services, as well as methods for data retrieval.
3. Learn to test database access methods using the Spring framework.
4. Acquire skills in creating Thymeleaf pages for displaying, adding, and editing table data.
5. Learn to create controller methods for handling server requests.
6. Improve the ability to develop user-friendly applications.



## Task Description
Develop a Spring application that displays information from two related database tables on web pages and supports CRUD operations.

The application should:
- Display the content of the main table on a webpage and provide data management features (search, filtering, sorting).
- Allow adding, editing, and deleting records in the main table while considering foreign key constraints and domain-specific rules.
- Display the content of the related table and provide similar management features (search, filtering, sorting).
- Support adding, editing, and deleting records in the related table while respecting foreign key constraints and data integrity.

A non-functional requirement is to ensure data completeness and validation, considering the domain specifics and field types.



## Implementation Steps
### 1. Create and configure a Spring Boot project
Implement the business logic layer (repository, service classes, and service implementation) and test CRUD methods for the first entity.

### 2. Develop the web interface layer
Develop the web interface layer (HTML pages and controllers) for the first entity. Implement sorting, filtering, and search functionality for the main table, as well as adding, editing, and deleting records.

### 3. Create an entity class for the second entity
Implement the business logic layer (repository, service classes, and service implementation) and test CRUD methods for the second entity.

### 4. Develop the web interface layer
Develop the web interface layer (HTML pages and controllers) for the second entity. Implement sorting, filtering, search, adding, editing, and deleting records while considering the relationship between the two entities.
