Entrant Table

Table with data on entrants of a certain higher education institution in Ukraine.

The table contains the following information about entrants:

  • Long unique identifier;
  • String case number of the personal file;
  • String surname;
  • String name;
  • String patronymic;
  • LocalDate date of birth;
  • Boolean gender;
  • Double rating score.

Student Table

Table with data on students of a certain higher education institution in Ukraine.

The table contains the following information about students:

  • Long unique identifier;
  • Entrant owner of personal information;
  • FundingType funding type under the study agreement (contract or budget);
  • ScholarshipStatus scholarship accrual status (none, ordinary or enhanced);
  • String address of corporate mail in NTU "KhPI".
